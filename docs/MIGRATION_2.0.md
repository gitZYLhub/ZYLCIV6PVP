# ZYLPVPMOD 2.0.0 迁移说明

## 安装与联机

1. 完全退出文明 VI。
2. 移除或禁用旧版 `ZYLPVPMOD 1.3.x/1.4.x`，只保留一个 `ZYLPVPMOD 2.0.0` 运行副本。
3. 所有联机玩家必须使用同一发布 profile 和完全相同的包内容；大厅版本握手应显示 `ZYLPVPMOD v2.0.0`。
4. 更新后首次进入游戏前重新启动文明 VI，避免旧 UI Context 或数据库缓存残留。

## 存档兼容

- Mod ID 保持 `4dd01931-9d44-4a8a-8e74-712cba0f0072`，用于让原存档识别同一 Mod；版本和显示名称升级为 2.0.0。
- 2.0.0 保留 1.3.0 的主要玩法内容和大厅选项，并已吸收 1.4.x 的俄罗斯、开局加成目标和四张富饶大陆地图改动；详细对账见 `PORT_1.4_TO_2.0.md`。地卜师仍出生自带 1 次，可立即创建 1 个地脉。
- 建议重要比赛从新局开始。旧存档升级后应重点检查秘密结社、开局加成持久化、身份局只读面板和回合计时器。
- 不支持在同一场联机游戏中混用 1.3.x、1.4.x 与 2.0.0；版本握手不一致时不要开始游戏。

## 发布包选择

- `universal`：同时包含 Windows 与 macOS 资产，适合通用分发。
- `windows` / `macos`：只保留目标平台资产，包体更小；所有参赛者应使用相同 profile。

静态校验与构建可由 `tools/validate.ps1` 和 `tools/build_workshop_release.ps1` 重现。文明 VI 新局、读档和双客户端场景仍应按 `docs/TEST_MATRIX.md` 完成人工验收。
