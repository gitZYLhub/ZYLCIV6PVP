## 联机故障与时序

| ID | 场景 | 期望 |
| --- | --- | --- |
| N01 | 客户端版本不一致 | 开局前明确阻止或告警，不静默继续 |
| N02 | 玩家掉线后重连 | 只恢复一次状态，无重复投票/单位/发牌 |
| N03 | 房主切换 | 权威端重新确定，旧广播不覆盖新状态 |
| N04 | 同一命令或版本回复重复到达 | 幂等处理，只产生一次效果；重复/迟到版本回复不重开 3/66/99 终态 |
| N05 | 广播乱序 | 旧状态版本被拒绝 |
| N06 | 热载入 UI | 事件不重复注册，控件状态恢复 |
| N07 | p+/p-/临时停表边界 | 权限、次数、下限和反馈正确 |
| N08 | 投票期间玩家槽变化 | 旧投票失效或一致迁移 |
| N09 | 身份发牌后设置变化 | 旧牌明确失效并要求重发 |
| N10 | 存档加载到不同本地 UI 设置 | 共享玩法不受本地配置污染 |
